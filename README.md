# 中央研究院 人文社會科學數位資料庫導覽與智能選庫系統（75+ 全景旗艦版）

本專案整合中央研究院人文社會科學組 **12 個研究所與研究中心、全院圖書館 300+ 資源、數位文化中心以及南部院區** 的 75+ 個核心原典資料庫與珍稀一手專題史料，並提供依研究領域分類、教材轉化指引與 **「研究課題智能選庫助手 (AI Advisor)」**。

## 🌟 核心特色

1. **75+ 專業原典資料庫與一手史料子庫**：
   * **古代文獻與金石考古**：居延漢簡字典、殷墟甲骨拓片、商周青銅拓片、漢代畫像石磚（武梁祠）、佛教造像拓片、遼金元石刻碑拓、傅斯年圖書館善本圖籍、徽州契約、藏印記、村寨網。
   * **近代中國與檔案文獻**：外交部檔案、民國婦女與性別史、胡適手稿書信、李國鼎科技檔案、朱家驊檔案、新華社內部參考。
   * **臺灣在地歷史與民間檔案**：臺灣史檔案系統、臺灣日記知識庫（林獻堂等）、臺灣總督府職員錄、出境旅券系統、臺灣古文書整合系統、日治寫真帖老照片、臺灣文藝雜誌庫、南部院區特展成果。
   * **外國史、西洋思潮與國際關係**：歐美研究季刊、British Periodicals 英國歷史期刊 (1680-1930)、Oxford DNB 牛津英國國家人物傳記、英國長老教會《使信月刊》宣教檔案、DBpia 韓國期刊、JSTOR 國際核心期刊。
   * **地理空間、語言與社會實證**：臺灣百年歷史疊圖、全臺詩地景 GIS、六朝疾病感覺地圖、歷代高僧遊方軌跡、閩客語辭典、臺灣南島語言典藏、上古近代漢語語料庫、臺灣社會變遷調查 (TSCS)、SRDA 學術調查數據庫、臺灣經驗實證調查 (TESD)。
   * **跨領域轉譯與商業大庫**：研之有物科普旗艦、研究資料寄存所 (depositar)、數位人文研究平台 (DADH)、全國報刊索引（晚清/民國期刊庫）、大成老舊刊、雕龍古籍、CNKI 中國知網。

2. **全院 300+ 資料庫一鍵跨庫穿透搜尋**：
   * 搜尋框即時連動中研院官方三大頂級元搜索引擎（中研院圖書館 300+ 總目錄、開放博物館 117 萬件藏品、數位文化中心典藏網），100% 覆蓋所有冷門或跨領域資料。

3. **研究課題智能選庫助手 (AI Advisor)**：
   * 師生輸入研究題目（如日治教育、家鄉百年地貌、古代疫病偏方、居延漢簡、英國維多利亞時代、民國女權），自動推薦首選起手資料庫與三階段研究路徑。

4. **每日自動化巡檢維護（GitHub Actions）**：
   * 內建自動化排程，每天早上 9:00（台灣時間）自動發送 HTTP 請求測試全庫網址，一旦斷鏈即時自動開 Issue 警示。

5. **單一頁面無依賴**：完全前端自包含架構，手機、平板、電腦皆可流暢開啟。

## 🚀 部署教學（不到 1 分鐘快速上線）

### 方式一：GitHub 網頁直接上傳（最直覺）
1. 在 GitHub 倉庫根目錄點擊 **Add file** ➔ **Upload files**。
2. 將本專案的 `index.html` 與 `README.md` 拖曳上傳至倉庫根目錄。
3. 捲動到底部點擊綠色按鈕 **Commit changes**。
4. 進入倉庫的 **Settings** ➔ **Pages**，將 **Source** 選擇 **Deploy from a branch**（選擇 `main` 分支與 `/ (root)`）。
5. 點擊 **Save**，約 30 秒後即可在專屬公開網址瀏覽：
   `https://<你的GitHub帳號>.github.io/as-humanities-db/`

### 方式二：使用 Git 命令列推送
```bash
git init
git add .
git commit -m "Update: Upgrade to 75+ databases flagship edition"
git branch -M main
git remote add origin https://github.com/<你的GitHub帳號>/<你的倉庫名稱>.git
git push -u origin main
```

## ⏰ 每日自動巡檢維護機制 (GitHub Actions)
* **執行排程**：每週一至週日，台灣時間每日上午 09:00 (`0 1 * * *` UTC)。
* **檢查腳本**：`scripts/check_links.py`。
* **異常報警**：若中研院某資料庫因伺服器維護或更換網址而回傳錯誤，GitHub Actions 會自動建立標記為 `broken-link` 的 Issue，並透過 Email 寄送通知。

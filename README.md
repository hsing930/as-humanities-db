> **策劃與建置**：國立斗六高級中學歷史科 **張志祥老師**  
> **線上發布站點**：[https://hsing930.github.io/as-humanities-db/](https://hsing930.github.io/as-humanities-db/)

## 📌 專案簡介與核心特色

本平臺旨在為高中歷史科教學、108 課綱「探究與實作」、小論文專題研究，以及大專人文學術研究者，建立一個全面、直觀且結構化的**中央研究院人文社會科學數位資源單一檢索入口**。

全平臺涵蓋中研院人文社會科學組全院 12 單位、跨學組中心，以及**中研院圖書館人文組全宗採購與館藏資料庫**，合計收錄高達 **393+ 個數位資料庫與數位典藏系統**。

### 🌟 四大系統核心功能
1. **三段式資料庫範圍切換（Scope Selector）**：
   - 🌐 **全庫總覽（393 庫）**：一鍵跨庫檢索全院自建數位典藏與外購商用資料庫。
   - 🎯 **教學研究精選（87 庫）**：精選高中歷史教學、小論文探究與實作、地圖 GIS、臺灣史之一手核心資料庫。
   - 🏛️ **圖書館全宗名冊（306 庫）**：中研院圖書館引進之海量古籍、近代報刊、外文文獻與東亞日文資料庫。
2. **研究課題智能選庫與教案顧問（AI Advisor）**：
   - 內建 12 套高中探究與實作引導方案（如「雲林與在地百年地景變遷」、「日治青年留學與旅券追蹤」、「商周甲骨金文與禮制變遷」等）。
   - 支援自然語言輸入研究課題，即時智能推薦最適合的研究庫與教學步驟。
3. **9 大研究領域分類導覽（0 筆無效類別全面剔除）**：
   - 近代中國與檔案文獻（85 庫）
   - 外國史、西洋思潮與國際關係（77 庫）
   - 中國古典與考古文獻（60 庫）
   - 跨領域策展、數位人文與科普（46 庫）
   - 臺灣在地歷史與民間檔案（45 庫）
   - 社會變遷、經濟法政與實證調查（41 庫）
   - 語言演變、文字學與語料庫（15 庫）
   - 族群文化、人類學與民俗（15 庫）
   - 地理空間、時空軌跡與 GIS（9 庫）
4. **全自動連結巡檢與健康監控（GitHub Actions）**：
   - 每天上午 9:00 自動執行 Python 巡檢腳本，檢測 393+ 連結之 HTTP 狀態碼與延遲。

## 🔐 資源使用權限與取用途徑指南

中研院資料庫因智慧財產權與採購合約，區分為四種取用模式：

| 權限分級標籤 | 收錄規模 | 代表性資料庫 | 校外師生取用建議 |
| :--- | :---: | :--- | :--- |
| 🟢 **全開放免 IP (Open Access)** | **87 庫** | 漢籍電子文獻、臺灣史檔案系統、臺灣日記知識庫、百年歷史地圖、小學堂、開放博物館 | **完全免費，免登入直接使用**。極適合高中探究與實作教學引導。 |
| 🟡 **院內 IP / VPN 遠端** | **78 庫** | 愛如生古籍/方志庫、晚清期刊、民國期刊、大成老舊刊、申報、字林西報 | 校外可免費查閱**書目與索引**；全文可至中研院南港院區或**台南沙崙南部院區「數位圖書檔案室」**（全院共享授權）查閱。 |
| 🔵 **校友 / 院內 SSO 遠端** | **172 庫** | HyRead、JSTOR、British Periodicals、Oxford DNB、雕龍古籍、臺灣日日新報 | 院內同仁/校友可遠端登入；高中端可透過大學圖書館聯盟或全國文獻傳遞 (NDDS) 申請借閱。 |
| 🟣 **實體館內單機 / 光碟** | **36 庫** | 人民日報50年圖文光碟、傳記文學單機版、新華社《內部參考》單機版 | 限定於各所實體圖書館專用工作站查閱。 |

## 🛠️ 專案檔案結構 (Repository Structure)

```text

├── .github/
│   └── workflows/
│       ├── deploy.yml            # GitHub Pages 自動部署工作流

```

## 🚀 快速更新與維護指南 (How to Update)

本專案採現代化「單一檔案（Single-file App）」架構，當您有任何更新時：

1. 開啟 GitHub 倉庫管理頁面。
2. 點選倉庫根目錄的 `index.html`。
3. 點選 **Add file** ➔ **Upload files**，拖入新的 `index.html`。
4. 點選 **Commit changes**。
5. GitHub Pages 將於 1~2 分鐘內自動完成編譯並發布！

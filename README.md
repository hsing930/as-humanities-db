## 📌 專案簡介與核心特色

本平臺旨在為高中歷史科教學、108 課綱「探究與實作」、小論文專題研究，以及大專人文學術研究者，建立一個全面、直觀且結構化的**中央研究院人文社會科學數位資源單一檢索入口**。

全平臺涵蓋中研院人文社會科學組全院 12 單位、跨學組中心，以及**中研院圖書館人文組全宗採購與館藏資料庫**，合計收錄高達 **393+ 個數位資料庫與數位典藏系統**。

### 🌟 五大系統核心功能
1. **三段式資料庫範圍切換（Scope Selector）**：
   - 🌐 **全庫總覽（393 庫）**：一鍵跨庫檢索全院自建數位典藏與外購商用資料庫。
   - 🎯 **教學研究精選（87 庫）**：精選高中歷史教學、小論文探究與實作、地圖 GIS、臺灣史之一手核心資料庫。
   - 🏛️ **圖書館全宗名冊（306 庫）**：中研院圖書館引進之海量古籍、近代報刊、外文文獻與東亞日文資料庫。
2. **研究課題智能選庫與教案顧問（AI Advisor）**：
   - 內建 12 套高中探究與實作引導方案（如「雲林與在地百年地景變遷」、「日治青年留學與旅券追蹤」、「商周青銅銘文」等）。
   - 支援自然語言輸入研究課題，即時智能推薦最適合的研究庫與教學步驟。
3. **9 大研究領域分類導覽（0 筆無效類別全面剔除）**：
   - 近代中國 (85)、外國西洋 (77)、古典考古 (60)、跨領域科普 (46)、臺灣在地 (45)、社會經政 (41)、語言文字 (15)、族群人類學 (15)、地理 GIS (9)。
4. **🛡️ 智能自我修復與全自動更新機制（Auto-Healing CI/CD）**：
   - 每天清晨 05:35 GitHub Actions 自動在雲端執行端點健康檢測。
   - **安全檢核門檻**：若偵測到任何 404 或主機失效，腳本會先自動啟動「備用官方端點替換」，並**嚴格要求 100% 連結確認可用**，才會自動 Commit 並發布！
5. **四級使用權限與取用途徑標註**：
   - 包含 🟢 全開放免 IP、🟡 院內/南院共享、🔵 校友/院內 SSO、🟣 館內單機等精確標籤。

## ⚙️ 如何開啟 GitHub 全自動更新功能（一次性設定）

為了讓 GitHub Actions 機器人能在每天清晨自動幫您維護更新，請至 GitHub 開啟寫入授權：

1. 開啟您的 GitHub 倉庫設定：`https://github.com/hsing930/as-humanities-db/settings/actions`
2. 捲動至 **Workflow permissions**。
3. 勾選 **「Read and write permissions」**（允許 Actions 寫入倉庫）。
4. 點選 **Save** 儲存。

完成後，GitHub 機器人每天就會自動為您巡檢、修復並發布，完全無需手動維護！
